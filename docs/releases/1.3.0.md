# 1.3.0 — şarkıya göre zaman kaydırma

Durum: **hazırlanıyor.** 1.2.0 Store'da yayında.

- İçerik: zaman kaydırma (+/− düğmeleri) artık her şarkı için ayrı saklanıyor. Yeni şarkı kendi kaydırmasıyla, yoksa 0 ile başlıyor; bir şarkıda yapılan düzeltme sonrakine geçmiyor.
- **Yeni saklanan veri var:** `offsets.json` (uygulamanın veri klasöründe), şarkının sadeleştirilmiş sanatçı ve adıyla kaydırma değeri. Gizlilik politikası güncellendi, site gönderimden önce yenilenmeli (aşağıda). Yeni bağlantı veya izin yok.

## Notes for certification (1986 karakter)

```text
Changes in this version: the time offset (toolbar - and + buttons) is now saved per song (artist, title and offset) in the app's AppData folder; each new song starts from its own offset or zero. Privacy policy updated. No new network calls or permissions.

Song recognition, on by default (gear > Song recognition): only when no lyrics source finds the current song, the app captures the player's sound output for 3 to 12 seconds via WASAPI loopback (not the microphone; no extra capability), computes an audio fingerprint in memory and sends only that to Shazam to learn the real song name, then searches again. Audio is never saved or uploaded. To see it: play https://www.youtube.com/watch?v=f-WWyliGQ8k in Microsoft Edge.

MrW Lyrics is a desktop lyrics viewer (WPF, MSIX). It reads the song playing on Windows through the System Media Transport Controls (the data behind the Windows media flyout) and shows its lyrics, synced line by line when available.

How to test:
1. Play a well-known song in an app shown in the Windows media flyout, e.g. Spotify, YouTube in Microsoft Edge, or Windows Media Player with a tagged file (Queen - Bohemian Rhapsody).
2. Start MrW Lyrics. Title, artist and lyrics appear within seconds; with synced lyrics the current line is highlighted.
3. Toolbar: pin = always on top, eye = lyrics-only mode, list = karaoke focus, gear = settings.

No account, sign-in, purchase or test credentials needed.

Network: track artist, title, album and duration go to lyrics services (lrclib.net, Musixmatch, YouTube Music, Genius, lyrics.ovh); the audio fingerprint goes to Shazam as above. No telemetry.

Files: settings and per-song offsets in the app's AppData folder; lyrics found are saved as .lrc/.txt in Music\Lyrics for offline reuse.

runFullTrust: Win32/WPF desktop app. It reads the Windows media session, saves lyrics to the Music folder and captures the player's sound output for song recognition. No services, drivers, startup tasks or admin rights.
```

## New in 1.3.0

- **Time offset per song.** When the lyrics run ahead of or behind a song, fix it once with the − and + buttons: the song comes back with that offset next time. A new song starts from its own offset, or from zero, so one song's correction no longer carries over to the next. Click the offset to reset it for that song.
- The offsets are stored on your device with the song's artist and title, in the app's own data folder. Nothing new is sent. The [privacy policy](https://lyrics.mrwproject.com/privacy/) lists what is stored.

## Bilinen risk ve sorunlar

- **Gayriresmî kaynaklar** önceki sürümdeki gibi varsayılan açık: Musixmatch (resmi olmayan mobil API), YouTube Music (resmi olmayan API, Android uygulaması gibi davranıyor), Genius (sayfa kazıma) ve Shazam (resmi olmayan uç nokta). Kullanım koşullarına aykırı olabilirler ve her an bozulabilirler; bozulursa zincir hatayı kaydedip sonraki kaynağa geçer. Sertifikasyon itiraz ederse ilk adımlar aynı: YouTube Music'i `ProviderCatalog.DefaultOrder` dışına almak, Shazam için `RecognizeUnfoundSongs` varsayılanını kapatmak (bkz. `docs/releases/1.1.0.md`, `docs/releases/1.2.0.md`). Bu sürüm gayriresmî kaynaklara daha fazla yaslanmıyor.
- **Eski genel kaydırma kayboluyor:** 1.2.0'da genel bir kaydırma ayarlamış kullanıcı güncellemeden sonra 0 görür. Bilinçli tercih: kaydırma artık şarkıya ait.
- **Aynı adlı farklı sürümler** (canlı kayıt ile albüm sürümü aynı adla bildirilirse) aynı kaydırmayı paylaşır; süre anahtara girmiyor.
- **Satır dolum efekti** (1.0.0'dan kalan): iki satıra kayan uzun satırlarda renk geçişi bloğu bir bütün olarak dolduruyor.
