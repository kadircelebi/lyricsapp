## Notes for certification (1986 karakter)

```text
Changes in this version: the settings window is titled "Settings" and shows a scroll bar. When the media session's app id names no process (some Edge profiles), song recognition now captures only the one app playing sound instead of the whole output. No new data, permissions or connections.

Song recognition, on by default (gear > Song recognition): only when no lyrics source finds the current song, the app captures the player's sound output for 3 to 12 seconds via WASAPI loopback (not the microphone; no extra capability), computes an audio fingerprint in memory and sends only that to Shazam to learn the real song name, then searches again. Audio is never saved or uploaded. To see it: play https://www.youtube.com/watch?v=f-WWyliGQ8k in Microsoft Edge.

MrW Lyrics is a desktop lyrics viewer (WPF, MSIX). It reads the song playing on Windows through the System Media Transport Controls (the data behind the Windows media flyout) and shows its lyrics, synced line by line when available.

How to test:
1. Play a well-known song in an app shown in the Windows media flyout, e.g. Spotify, YouTube in Microsoft Edge, or Windows Media Player with a tagged file (Queen - Bohemian Rhapsody).
2. Start MrW Lyrics. Title, artist and lyrics appear within seconds; with synced lyrics the current line is highlighted.
3. Toolbar: pin = always on top, eye = lyrics-only mode, list = karaoke focus, gear = settings.

No account, sign-in, purchase or test credentials needed.

Network: track artist, title, album and duration go to lyrics services (lrclib.net, Musixmatch, Genius, lyrics.ovh); the audio fingerprint goes to Shazam as above. No telemetry.

Files: settings in the app's AppData folder; lyrics found are saved as .lrc/.txt in Music\Lyrics for offline reuse.

runFullTrust: Win32/WPF desktop app. It reads the Windows media session, saves lyrics to the Music folder and captures the player's sound output for song recognition. No services, drivers, startup tasks or admin rights.
```

```markdown
MrW Lyrics 1.1.1 is a small update to the song recognition added in 1.1.0.

<a href="https://apps.microsoft.com/detail/9n5x2vhwxjwq"><img src="https://get.microsoft.com/images/en-us%20dark.svg" alt="Get it from Microsoft" width="200"></a>

## New in 1.1.1

- **Settings:** the window is now called Settings and has a visible scroll bar, so the Song recognition section at the bottom is easy to reach.
- **Recognition listens only to your player in more cases:** when the media session reports an app id that names no process (Microsoft Edge with several profiles, for example), the app now captures the one app that is playing sound instead of the whole sound output. If several apps are playing, it still falls back to the whole output.

## Install

Get it from the [Microsoft Store](https://apps.microsoft.com/detail/9n5x2vhwxjwq) (free, Windows 10 1809 or later, x64 and ARM64). If you already have it, the Store updates it. To build from source, see the [README](https://github.com/kadircelebi/lyricsapp#build-from-source).
```

# Checklist

## Bu sürümde

- **Oynatıcıyı bulma:** medya oturumunun bildirdiği uygulama kimliği hiçbir sürece karşılık gelmiyorsa (bazı Edge profilleri `F0DC299D809B9700` gibi bir kimlik bildiriyor), varsayılan hoparlörde o an ses çıkaran tek süreç dinleniyor (`LoopbackAudio.FindOnlyAudibleProcess`, 300 ms boyunca 5 örnek). Birden fazla süreç ses çıkarıyorsa eskisi gibi tüm çıkış dinleniyor. Probe'a `--source-app <kimlik>` eklendi.
