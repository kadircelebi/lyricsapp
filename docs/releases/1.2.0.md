# 1.2.0 — YouTube Music kaynağı ve Türkçe büyük harf eşleştirmesi

Durum: **Store'da yayında** (gönderim 2026-10-31, Submission 4; 2026-11-07'de yayında görüldü). Etiket `v1.2.0`, GitHub release yayında (release iş akışı başarılı). Gizlilik sayfası güncellendi. 1.1.1 Store'da yayında.

- İçerik: yeni söz kaynağı YouTube Music (Musixmatch ile Genius arasında, varsayılan açık) ve eşleştiricide `İ` harfi düzeltmesi.
- **Yeni bağlantı var:** sanatçı ve şarkı adı `music.youtube.com` adresine gidiyor. Gizlilik politikası güncellendi, site gönderimden önce yenilenmeli (aşağıda).

## Notes for certification (1992 karakter)

```text
Changes in this version: a new lyrics source, YouTube Music, is on by default. The track's artist and title go to music.youtube.com, then the id of the song it found; no account is used. Privacy policy updated. Song names in Turkish capitals now match correctly. No new permissions.

Song recognition, on by default (gear > Song recognition): only when no lyrics source finds the current song, the app captures the player's sound output for 3 to 12 seconds via WASAPI loopback (not the microphone; no extra capability), computes an audio fingerprint in memory and sends only that to Shazam to learn the real song name, then searches again. Audio is never saved or uploaded. To see it: play https://www.youtube.com/watch?v=f-WWyliGQ8k in Microsoft Edge.

MrW Lyrics is a desktop lyrics viewer (WPF, MSIX). It reads the song playing on Windows through the System Media Transport Controls (the data behind the Windows media flyout) and shows its lyrics, synced line by line when available.

How to test:
1. Play a well-known song in an app shown in the Windows media flyout, e.g. Spotify, YouTube in Microsoft Edge, or Windows Media Player with a tagged file (Queen - Bohemian Rhapsody).
2. Start MrW Lyrics. Title, artist and lyrics appear within seconds; with synced lyrics the current line is highlighted.
3. Toolbar: pin = always on top, eye = lyrics-only mode, list = karaoke focus, gear = settings.

No account, sign-in, purchase or test credentials needed.

Network: track artist, title, album and duration go to lyrics services (lrclib.net, Musixmatch, YouTube Music, Genius, lyrics.ovh); the audio fingerprint goes to Shazam as above. No telemetry.

Files: settings in the app's AppData folder; lyrics found are saved as .lrc/.txt in Music\Lyrics for offline reuse.

runFullTrust: Win32/WPF desktop app. It reads the Windows media session, saves lyrics to the Music folder and captures the player's sound output for song recognition. No services, drivers, startup tasks or admin rights.
```

## New in 1.2.0

- **YouTube Music is a new lyrics source.** It sits between Musixmatch and Genius, and it brings line-by-line timing to songs that only had plain text. If you already have the app, it is added to your sources once.

## Bilinen risk ve sorunlar

- **YouTube Music** resmi olmayan bir API ve Android uygulaması gibi davranıyor. Kullanım koşullarına aykırı olabilir ve her an bozulabilir; bozulursa zincir hatayı kaydedip sonraki kaynağa geçer. Bu, gayriresmî kaynaklara daha fazla yaslanmak demek; 2026-10-31'de kullanıcının bilerek verdiği karar. Sertifikasyon itiraz ederse ilk adım bu kaynağı `ProviderCatalog.DefaultOrder` dışına almak.
- **Musixmatch** (resmi olmayan mobil API), **Genius** (sayfa kazıma) ve **Shazam** (resmi olmayan uç nokta) önceki sürümlerdeki gibi varsayılan açık. Risk ve ilk adımlar aynı (bkz. `docs/releases/1.1.0.md`).
- **LrcLib kararsız:** 2026-10-31 denemesinde yavaş tekrarda bile 50 aramanın 21'i hata verdi (görülen hata 503). Zincir durmuyor, sonraki kaynağa geçiyor.
- **Tek sürüme bakılıyor:** YouTube Music en iyi eşleşen tek şarkıyı dener; o sürümde zamanlı söz yoksa başka sürüme bakılmaz (denemede 2 şarkı bu yüzden muhtemelen düz söz kaldı).
- **Zamanlama:** Musixmatch ile karşılaştırıldı (ilk satır farkı en çok 2,6 sn), sesle dinlenerek kontrol edilmedi.
- **Yerel önbellek süreye bakmıyor:** tanınan adla aynı adlı bir dosya varsa, farklı uzunluktaki bir yükleme için de o kullanılır.
- **Satır dolum efekti** (1.0.0'dan kalan): iki satıra kayan uzun satırlarda renk geçişi bloğu bir bütün olarak dolduruyor.
